## Selected Open-Source Systems

### Lookalike Rerank

LLM reasoning layer for company-search reranking.

- +17.6 average Precision@100 across seven difficult benchmark seeds
- Veeva: 58.5% → 88.5%
- Nubank: 50.0% → 81.5%
- Reproducible for under $5

[Repository](https://github.com/akkupratap323/lookalike-rerank)

### Clawspan

Voice-first, locally running multi-agent system for macOS, built from scratch
without LangChain or CrewAI.

- Coordinates 8+ specialized agents
- Three-tier router handles ~80% of requests without an LLM
- Persistent memory using ChromaDB and a knowledge graph

[Repository](https://github.com/akkupratap323/Clawspan)

### PersonaAI

Real-time multi-persona Voice AI platform with 1–1.5-second end-to-end latency.

- Six personas with live agent transfer and context handoff
- Deepgram, DeepSeek, Cartesia and Pipecat
- Emotion-aware responses using wav2vec2 and Gemini

[Repository](https://github.com/akkupratap323/MultiPersona-AI-voice-agents) ·
[Live Demo](https://3.6.92.112.nip.io/)
